# APS Calendar

Static GitHub Pages site for the 2026–27 Attleboro Public Schools district calendar.

## Local preview

```sh
python3 -m http.server 8000 --directory apscalendar
```

Open <http://localhost:8000>.

The calendar data in `index.html` reflects the official APS calendar approved March 3, 2026. The scheduled 180th school day is June 16, 2027; the calendar includes a June 24, 2027 make-up-day scenario for five cancellations.
